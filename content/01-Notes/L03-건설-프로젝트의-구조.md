# L03. 건설 프로젝트의 구조

## 강의 중점
- 건설 프로젝트의 생애주기(Life Cycle)
- 건설산업의 참여 주체와 역할
- 건설 프로젝트 수행 체계

## 학습 목표
1. 건설 프로젝트의 생애주기와 각 단계별 주요 활동을 설명할 수 있다.
2. 건설산업의 참여 주체(발주자, 설계자, 시공자, 감리자)의 역할을 이해한다.

## 강의 내용

### 건설 프로젝트 생애주기 (Life Cycle)
```
기획 → 설계 → 시공 → 유지관리 → 해체/리모델링
```

1. **기획 단계**: 타당성 조사, 사업계획 수립, 예산 확보
2. **설계 단계**: 기본설계 → 실시설계, 구조/설비/건축 설계
3. **시공 단계**: 착공 → 골조 → 마감 → 준공
4. **유지관리 단계**: 시설물 점검, 보수/보강, 에너지 관리
5. **해체/리모델링**: 수명 종료 후 해체 또는 용도 변경

### 건설산업의 참여 주체
| 참여 주체 | 역할 | 관련 자격 |
|-----------|------|-----------|
| **발주자** (Owner) | 사업 기획, 자금 조달, 의사결정 | - |
| **설계자** (Designer) | 건축/구조/설비 설계 | 건축사 |
| **시공자** (Contractor) | 현장 시공, 하도급 관리 | 건설기술인 |
| **감리자** (Supervisor) | 설계 의도 구현 감독, 품질 확인 | 건축사, 기술사 |
| **CM** (Construction Manager) | 종합 관리 (공정, 원가, 품질, 안전) | 건설사업관리기술인 |

### 프로젝트 발주 방식
- **설계-시공 분리 발주 (DBB)**: 전통적 방식, 설계 후 시공 입찰
- **설계-시공 일괄 발주 (DB/Turn-key)**: 하나의 업체가 설계+시공
- **CM at Risk**: CM이 비용 보증
- **IPD (Integrated Project Delivery)**: 통합 프로젝트 수행
