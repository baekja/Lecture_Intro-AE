# L24. 디지털 트윈과 신기술

> [!warning] 5/25(월)은 부처님 오신날 (공휴일) - 보강 일정 확인 필요

## 강의 중점

## 학습 목표
1. IoT/센서 기반 스마트 건설 기술의 원리와 적용 사례를 이해한다.
2. 디지털 트윈의 개념과 건축물 관리에서의 활용 가능성을 파악한다.

## 강의 내용

> [!info] W14 연결
> 이번 주에 배우는 IoT, 디지털 트윈, 센서 기술이 [[L27-스마트-빌딩|L27 스마트 빌딩]]에서 건물 운영·관리로 확장됩니다.

### 디지털 트윈 (Digital Twin)
- **정의**: 물리적 건축물의 가상 복제본으로 실시간 동기화
- **구성 요소**:
  1. 물리적 건물 (Physical Entity)
  2. 디지털 모델 (BIM 기반)
  3. IoT 센서 데이터 (실시간 연결)
  4. 데이터 분석 플랫폼 (AI/ML)
- **활용 분야**:
  - 시공 중: 공정 모니터링, 품질 관리
  - 운영 중: 에너지 최적화, 예방 정비, 공간 활용 분석
  - 비상 상황: 재난 시뮬레이션, 피난 경로 분석

### 드론 (UAV) 활용
- **측량**: 항공 사진 측량, 3D 지형 모델 생성
- **현장 관리**: 공정 진행 모니터링 (사진/영상)
- **안전 점검**: 고소 작업 대체, 외벽/지붕 점검
- **자산 관리**: 대규모 시설물 정기 점검

### 3D 스캐닝/포인트 클라우드
- **LiDAR 기반 3D 스캔**: 기존 건물의 현황 측량
- **포인트 클라우드 → BIM**: Scan-to-BIM 프로세스
- **활용**: 리모델링 설계, 준공 검증, 시설물 관리

### AR/VR/MR 기술
| 기술 | 설명 | 건축 적용 |
|------|------|-----------|
| VR | 가상 현실 (완전 몰입) | 설계 리뷰, 가상 모델하우스 |
| AR | 증강 현실 (현실+가상 중첩) | 현장 검측, 배관 위치 확인 |
| MR | 혼합 현실 (상호작용) | BIM 모델 현장 오버레이 |
