# L21. BIM 기본 개념

## 강의 중점
- BIM(Building Information Modeling)의 정의와 개념
- BIM 소프트웨어와 실무 워크플로우

## 학습 목표
1. BIM의 정의, 특징, 기존 CAD와의 차이를 설명할 수 있다.

## 강의 내용

### BIM의 정의
- **BIM**: 건축물의 물리적/기능적 특성을 3D 모델에 통합 관리하는 프로세스
- **핵심**: 3D 형상 + 속성 정보 (재료, 비용, 일정 등) 통합
- **CAD vs BIM**:

| 구분 | 2D CAD | BIM |
|------|--------|-----|
| 표현 | 선(Line) 기반 | 객체(Object) 기반 |
| 정보 | 도면 정보만 | 재료, 비용, 일정 등 통합 |
| 연동 | 도면 간 수동 연동 | 자동 연동 (하나 수정 → 전체 반영) |
| 활용 | 도면 작성 | 설계~유지관리 전 과정 |

### BIM의 차원(Dimension)
- **3D BIM**: 3차원 형상 모델링
- **4D BIM**: 3D + 시간 (공정 시뮬레이션)
- **5D BIM**: 4D + 비용 (물량/원가 산출)
- **6D BIM**: 5D + 지속가능성 (에너지 분석)
- **7D BIM**: 6D + 시설관리 (FM)

### BIM 소프트웨어
| 소프트웨어 | 용도 | 개발사 |
|------------|------|--------|
| Revit | 건축/구조/MEP 설계 | Autodesk |
| ArchiCAD | 건축 설계 | Graphisoft |
| Tekla Structures | 구조 상세 설계 | Trimble |
| Navisworks | 간섭 검토, 4D 시뮬레이션 | Autodesk |
| Solibri | 모델 검토, 규정 검증 | Nemetschek |
