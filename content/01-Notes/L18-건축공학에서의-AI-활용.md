# L18. 건축공학에서의 AI 활용

## 강의 중점
- 건축공학 분야에서의 AI 활용 사례
- AI 기반 건축 설계 및 구조 해석 사례

## 학습 목표
1. 건축공학 분야에서 AI가 활용되는 구체적 사례를 3가지 이상 설명할 수 있다.
2. AI 기술이 건축공학에 가져올 변화와 한계를 논의할 수 있다.

## 강의 내용

### 구조공학 분야
- **구조 최적설계**: AI 기반 부재 크기/배치 최적화
- **손상 탐지**: 진동 데이터 + ML로 구조물 건전성 평가
- **내진 성능 예측**: 딥러닝 기반 지진 응답 예측
- **균열/결함 탐지**: CNN 기반 이미지 분석 자동 탐지

### 건축환경/에너지 분야
- **에너지 소비 예측**: 건물 에너지 사용량 ML 기반 예측
- **HVAC 최적 제어**: 강화학습 기반 실시간 공조 제어
- **자연채광 최적화**: AI 기반 창호/차양 설계

### 건설관리 분야
- **공정 예측**: 프로젝트 일정 지연 예측
- **안전 관리**: CCTV + AI로 현장 안전 위반 자동 감지
- **물량/원가 예측**: 설계 초기 단계 AI 기반 개산견적

### 설계 분야
- **생성형 설계 (Generative Design)**: AI가 다수의 설계 대안 자동 생성
- **평면 자동 생성**: GAN 기반 건축 평면도 생성
- **3D 모델 자동화**: Point Cloud → BIM 자동 변환

### AI 활용의 한계와 과제
- 데이터 부족: 건설 분야 정형 데이터 축적 미흡
- 해석 가능성 (Explainability): 블랙박스 모델의 신뢰성 문제
- 책임 소재: AI 판단 오류 시 법적 책임
- 기존 워크플로우 통합: 현업 적용의 어려움
