# L22. BIM 활용과 국내 동향

## 강의 중점
- BIM의 발전 과정과 국내외 동향
- BIM 기반 설계/시공/유지관리 활용

## 학습 목표
1. BIM의 설계-시공-유지관리 전 생애주기 활용 방법을 이해한다.
2. 국내 BIM 의무화 정책 동향과 실무 적용 현황을 파악한다.

## 강의 내용

### 설계 단계 BIM 활용
- **건축 설계**: 3D 매스 스터디, 평면/입면/단면 자동 생성
- **구조 설계**: 구조 모델링 → 해석 연동 → 배근 상세
- **MEP 설계**: 덕트/배관 라우팅, 장비 배치
- **간섭 검토 (Clash Detection)**: 건축-구조-설비 간 물리적 충돌 자동 탐지

### 시공 단계 BIM 활용
- **4D 시뮬레이션**: 공정별 3D 모델 시각화, 공정 최적화
- **5D 물량산출**: BIM 모델에서 자동 물량 산출 → 공사비 산정
- **시공성 검토**: 양중 계획, 가설 계획 시뮬레이션
- **현장 관리**: 모바일 BIM, AR/MR 활용 현장 검측

### 유지관리 단계 BIM 활용
- **시설물 관리 (FM)**: BIM 모델 기반 시설물 이력 관리
- **에너지 관리**: BIM 연계 에너지 시뮬레이션
- **리모델링**: 기존 건물 3D 스캔 → BIM 모델 구축

### 국내 BIM 정책 동향
- **조달청**: 500억원 이상 공공건축물 BIM 설계 의무화 (2025~)
- **국토교통부**: 건축 BIM 활성화 로드맵
- **건축 BIM 지침**: 국토교통부 고시, LOD 기준
- **openBIM**: IFC 표준, 소프트웨어 간 호환성

### LOD (Level of Development)
| LOD | 단계 | 설명 |
|-----|------|------|
| 100 | 개념 설계 | 매스 모델, 대략적 형상 |
| 200 | 기본 설계 | 주요 부재 형상, 개략 치수 |
| 300 | 실시 설계 | 정확한 치수, 재료 정보 |
| 350 | 시공 상세 | 접합 상세, 시공 정보 |
| 400 | 제작/시공 | 제작도 수준 상세 |
| 500 | 준공/운영 | 실측 정보 반영 (as-built) |
