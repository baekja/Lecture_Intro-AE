# L23. 건축공학과 IT 기술

## 강의 중점
- 건축공학에서의 IT 기술 활용 전반
- IoT/센서 기반 스마트 건설 기술
- 클라우드·모바일 기술의 건설 현장 적용

## 학습 목표
1. 건축공학 분야에서 활용되는 IT 기술의 종류와 역할을 설명할 수 있다.

## 강의 내용

### 건설 IT의 발전 과정
```
2D CAD → 3D CAD → BIM → 스마트 건설 → AI/디지털 트윈
(1980s)  (1990s)  (2000s)  (2010s)      (2020s~)
```

### IoT (Internet of Things) in Construction
- **정의**: 사물에 센서와 통신 기능을 내장하여 데이터 수집/분석
- **건설 현장 IoT 적용**:
  - 구조물 건전성 모니터링 (SHM): 변위, 가속도, 변형률 센서
  - 환경 모니터링: 온도, 습도, 분진, 소음 측정
  - 장비 관리: GPS 기반 건설 장비 위치 추적
  - 안전 관리: 작업자 위치 추적 (RTLS), 웨어러블 디바이스

### 클라우드 컴퓨팅과 건설
- **클라우드 기반 협업**: BIM 360, Procore, PlanGrid
- **장점**: 실시간 데이터 공유, 원격 협업, 모바일 접근성
- **건설 데이터 관리**: 도면, 사진, 보고서의 체계적 관리

### 모바일 기술
- 현장 도면 확인 (태블릿/스마트폰)
- 현장 검측 및 품질 점검 앱
- 사진 기반 공정 기록 자동화
