# L26. LLM의 건축공학 활용

## 강의 중점
- LLM의 건축공학 분야 활용 가능성
- AI 코파일럿 시대의 건축공학도 역량

## 학습 목표
1. LLM을 건축공학 실무(설계, 시공, 연구)에 활용하는 방법을 이해한다.
2. 프롬프트 엔지니어링의 기본 원리를 이해하고 간단한 프롬프트를 작성할 수 있다.

## 강의 내용

### 설계 단계 활용
- **설계 기준 조회**: KDS/KBC 기준 해석 보조
- **설계 검토 보조**: 구조계산서 검토, 설계 조건 확인
- **보고서 작성**: 구조계산서, 설계 설명서 초안 작성
- **코드 생성**: Python/MATLAB 기반 구조 해석 코드 작성 지원

### 시공/관리 단계 활용
- **시방서 분석**: 시방서 내용 요약 및 핵심 조항 추출
- **RFI (Request for Information) 작성**: 현장 질의서 작성 보조
- **안전 계획 수립**: 위험성 평가 보고서 초안 작성
- **회의록 작성**: 음성 인식 + LLM으로 회의록 자동 생성

### 연구/교육 활용
- **논문 분석**: 학술 논문 요약, 핵심 내용 추출
- **문헌 조사 보조**: 연구 주제 관련 문헌 검색 방향 제시
- **코딩 보조**: 데이터 분석, 시뮬레이션 코드 작성
- **학습 보조**: 개념 설명, 문제 풀이 과정 안내

### LLM 활용 시 주의사항
> [!important] 핵심 원칙
> - **검증 필수**: LLM 출력은 반드시 전문가가 검증해야 한다
> - **출처 확인**: 참고문헌/기준 인용 시 실제 존재 여부 확인
> - **보안 주의**: 기밀 정보, 개인정보를 LLM에 입력하지 않기
> - **보조 도구**: LLM은 의사결정 "보조" 도구, 최종 판단은 엔지니어

### AI 시대의 건축공학도 역량
1. **기본기 확보**: 구조역학, 재료역학, 건축법규 등 전문 지식
2. **디지털 리터러시**: BIM, 프로그래밍, 데이터 분석 능력
3. **AI 활용 능력**: 프롬프트 엔지니어링, AI 도구 활용
4. **비판적 사고**: AI 결과를 검증하고 판단하는 능력
5. **융합적 사고**: 기술 간 연결, 창의적 문제 해결

## 실습/과제
- [ ] **실습+과제 (통합)**: ChatGPT 또는 Claude를 활용하여 다음 중 **2가지**를 수행하고 **대화 캡처 + 결과 검증** 제출:
  1. 단순보의 반력 계산 문제를 풀어달라고 요청하고 결과 검증
  2. 건축 관련 Python 코드를 작성하도록 요청하고 실행
  3. 건축법규/설계기준 관련 질문을 하고 답변의 정확성 검증
  4. 건축공학 실무/연구 시나리오를 제안하고 LLM의 가능성과 한계 분석
  - 제출 형식: **대화 캡처(스크린샷) + 검증/분석 코멘트** (자유 형식)
  - 제출 방식: 이메일 (조교)
